![Pomodoro Timer](https://img.shields.io/badge/Pomodoro-Productivity-red.svg) ![Status](https://img.shields.io/badge/Status-Active-brightgreen.svg) ![Stars](https://img.shields.io/github/stars/mukiralad/pomodoro_timer.svg) ![License](https://img.shields.io/github/license/mukiralad/pomodoro_timer)

Welcome to **Pomodoro Timer**! This web application helps you enhance productivity using the famous **Pomodoro Technique**. The Pomodoro Technique is a time management method that involves breaking work into focused intervals, typically 25 minutes long, separated by short breaks. This application provides a clean interface to manage your work sessions effectively, making it perfect for students, developers, writers, and anyone looking to stay focused.

## Features
- **Pomodoro Timer**: Set work intervals (default 25 minutes) and short breaks.
- **Simple and Intuitive Interface**: A user-friendly interface for tracking work/break cycles.
- **Progress Tracker**: Track the number of Pomodoro sessions completed.
- **Customization**: Easily modify timer durations according to your needs.
- **Audio Alerts**: Get notified when work or break sessions end.
- **Responsive Design**: Works on mobile, tablet, and desktop devices.

## Installation
Follow the detailed steps below to set up everything needed to run this project locally.

### 1. Clone the Repository
First, clone this repository to your local machine:

```sh
$ git clone https://github.com/mukiralad/pomodoro_timer.git
$ cd pomodoro_timer
```

### 2. Install Dependencies
Ensure you have **Node.js** and **npm** installed. Then, install the required dependencies using `npm`:

```sh
$ npm install
```

### 3. Run the Application
To start the application in development mode, use the following command:

```sh
$ npm run dev
```

This command will start a local server, and you can view the application by navigating to `http://localhost:3000` in your web browser.

## Setup Instructions

### 1. Environment Variables

To build and run the application in production mode, use:

```sh
$ npm run build
$ npm start
```

## Usage Guide
- **Start a Pomodoro Session**: Click the **Start** button to begin a Pomodoro (25-minute) work session.
- **Take Breaks**: Once the work session ends, click **Start Break** to begin a 5-minute break.
- **Track Your Progress**: Each completed Pomodoro session is counted towards your daily goal.
- **Customize Timer Durations**: You can adjust work and break durations as per your preferences.

## Customization
You can easily customize the application to meet your needs:
- **Modify Timer Durations**: Edit the `page.tsx` file to change the default Pomodoro and break durations.
- **Theme Changes**: Update the CSS to change the look and feel of the application.
